# 📝 Sign-up / Registration Page

A clean and modern **Sign-In / Registration page** created using HTML and CSS.

## 📌 About the Project

This project is a front-end registration page designed with a simple and attractive user interface.

The page allows users to enter their username, email address, phone number, password, and confirm password.

## ✨ Features

* 👤 Username field
* 📧 Email address field
* 📱 Phone number field
* 🔑 Password field
* 🔐 Confirm Password field
* 🖼️ Office-themed image section
* 🎨 Custom CSS styling
* 🖱️ Button hover effect
* ✨ Clean and simple design

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `signin.html`.
4. Right-click on the file.
5. Select **Open with Live Server**.

The Sign-In page will open in your web browser.
